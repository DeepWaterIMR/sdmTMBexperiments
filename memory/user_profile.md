# User profile

The package author/maintainer is a fisheries scientist who develops R packages
for marine/fisheries science (e.g. ggOceanMaps, ggFishPlots, RstoxUtils) and
uses `sdmTMB` for spatiotemporal survey-index modelling.

## Working preferences (public-safe)
- R packages follow a consistent house style: roxygen2 docs, GPL-3, GitHub +
  pkgdown site, R-CMD-check CI, `Authors@R` with ORCID and institutional
  affiliation.
- Function/argument naming should align with the ecosystem being extended — here,
  `sdmTMB` (see [naming-conventions.md](naming-conventions.md)).
- Public repositories must not contain personal information or local paths (see
  [no-personal-info.md](no-personal-info.md)).
- Prefer fixing known bugs during refactors rather than carrying them forward
  (see [known-fixes.md](known-fixes.md)).

Keep this file free of personal contact details beyond the public package
metadata.
